# Student Learning Portal - PROG211 Assignment

## Overview
This repository contains a Python command-line application developed for the **PROG211 Object-Oriented Programming 1** assignment at Limkokwing University of Creative Technology, Sierra Leone. The application models a Digital Exam & Results Management System.

## Digital Public Goods (DPG) Alignment
This project complies with core Digital Public Goods standards:
1. **Open-Source**: Published under an open-source license on GitHub for public academic review.
2. **Inclusive and Accessible Design**: Built using lightweight, standard Python libraries (`.py`), requiring minimal hardware requirements to ensure accessibility across developing educational environments.
3. **Privacy-Respecting**: No sensitive, private, or encrypted personal data (such as government IDs or private credentials) are stored; the system uses generic sample identifiers.
4. **Modular and Reusable**: Cleanly separated into distinct classes (`Student` and `PortalManager`) following proper object-oriented encapsulation and modularity principles.

## Features
- **OOP Principles**: Implements classes, objects, instance methods, and class methods (`@classmethod`).
- **Data Structures**: Utilizes a Python dictionary for fast record lookups by unique Student IDs, alongside tuples for secure storage of scores and grades.
